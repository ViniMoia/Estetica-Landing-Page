# 🌸 Kellen Santos — Estética Avançada & Depilação a Laser

Landing page institucional e de alta conversão desenvolvida para a clínica boutique **Kellen Santos Estética Avançada**, localizada em Ananindeua - PA.

O projeto combina uma identidade visual sofisticada (*Dark Luxury* com acabamento dourado, glassmorphism e iluminação dinâmica) a funcionalidades interativas pensadas para proporcionar uma experiência de navegação premium e converter visitantes em agendamentos diretos via WhatsApp.

---

## ✨ Destaques & Funcionalidades

- **Design System Premium (Dark Luxury):**
  - Paleta com tons escuros profundos (`#08080A`), acabamentos em dourado refinado (`#E5C158`) e detalhes em vidro fosco (*glassmorphism*).
  - Efeito sutil de textura (*noise overlay*) e iluminação dinâmica reativa ao cursor (*flashlight zone*).
  - Animações refinadas de entrada e rolagem (*Scroll Reveal*, revelação tipográfica e contadores dinâmicos de métricas).

- **Quiz Interativo — "Descubra Seu Protocolo Ideal":**
  - Permite que o paciente selecione seu foco estético (ex.: Rejuvenescimento Facial, Contorno Mandibular, Depilação Definitiva, Qualidade da Pele, Firmeza Corporal).
  - Exibe na hora o protocolo recomendado e monta uma mensagem personalizada de agendamento direto para o WhatsApp da clínica.

- **Filtro de Procedimentos por Categoria:**
  - Visualização dinâmica dos tratamentos disponíveis com transições suaves e sem recarregamento de página.

- **FAQ Interativo:**
  - Acordeão sanfona inteligente para esclarecimento rápido de dúvidas frequentes sobre procedimentos, recuperação e formas de pagamento.

- **Integração Completa com WhatsApp:**
  - CTAs estratégicos e botão flutuante com mensagens pré-formatadas para facilitar o primeiro contato do cliente.

- **Totalmente Responsivo:**
  - Experiência otimizada para smartphones, tablets e desktops com menu drawer dinâmico para mobile.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura semântica, acessibilidade e SEO local (Ananindeua/PA).
- **Tailwind CSS:** Utilitários modernos para estilização ágil.
- **CSS3 Personalizado:** Efeitos visuais avançados, gradientes dourados, animações de brilho (*shimmer*), *glassmorphism* e sombras volumétricas.
- **JavaScript (Vanilla / ES6+):** Motor de microinterações, observadores de interseção (*IntersectionObserver*), efeito lanterna e lógica do quiz.
- **Iconify (Solar Icons):** Ícones vetoriais modernos e leves.
- **Google Fonts (Inter):** Tipografia contemporânea de alta legibilidade.

## 🚀 Como Executar Localmente

Como o projeto é construído em tecnologia web estática pura (HTML, CSS e JS), não há necessidade de instalação de dependências pesadas:

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/SEU_USUARIO/SEU_REPOSITORIO.git
   ```

2. **Acesse o diretório:**
   ```bash
   cd Kellen_Santos
   ```

3. **Abra o projeto:**
   - Dê um duplo clique no arquivo `index.html`, **OU**
   - Utilize a extensão **Live Server** no VS Code para rodar um servidor local com recarregamento em tempo real.
